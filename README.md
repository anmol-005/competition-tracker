# Real-Time Competitor Strategy Tracker for E-commerce

**Project Status: Milestone 1 Complete**

This project focuses on creating a real-time competitive intelligence tool for e-commerce businesses using LLMs (like OpenAI GPT, Meta LLaMA) and machine learning. The system monitors competitor pricing, discount strategies, and customer sentiment across various platforms to generate strategic insights and recommend responsive actions.

---

## 🎯 Milestone 1: Introduction & Initial Setup

This initial phase of the project focused on setting up the core infrastructure, preparing the team, and beginning the data aggregation process.

### Objectives Achieved:
* ✅ **Project Infrastructure:** Set up the development environment and foundational code structure.
* ✅ **Tool Training:** Familiarized the team with the core technologies, including LLMs and web scraping tools.
* ✅ **Initial Data Collection:** Developed and tested initial scripts to gather pricing and discount data from target e-commerce platforms.
